# 2026 국민대 자율주행 대회용 Xycar 주행 시스템

카메라 기반 학습 주행, OpenCV 차선 인식, LiDAR 장애물 회피, 신호등 인식을 구성한 ROS 2 기반 자율주행 프로젝트입니다.

기본 주행 명령과 미션별 제어 명령을 분리하고, MUX에서 우선순위에 따라 최종 차량 명령을 선택하도록 설계했습니다.

## 주요 기능

- **학습 기반 주행**: PilotNet 계열 CNN을 이용한 카메라 영상 기반 조향·속도 회귀
- **데이터 수집 및 학습**: 주행 이미지와 제어값 저장, 데이터 전처리 및 모델 학습
- **영상 기반 차선 추종**: 어안 보정, 흰색·노란색 차선 검출, 필터링된 PD 조향 제어
- **라바콘 회피**: LiDAR 기반 라바콘 구간 제어
- **동적 장애물 회피**: 전방 장애물의 연속 검출에 따른 회피 및 기본 주행 복귀
- **신호등 인식**: YOLO ONNX 기반 신호등 위치 검출과 색상·슬롯 기반 상태 판별
- **명령 중재**: 신호등·라바콘·동적 장애물·기본 주행 명령의 우선순위 관리
- **ROS 1 연동**: Docker와 ros1_bridge를 통한 기존 모터 드라이버 연결

## 통합 주행 구조

카메라 → E2E 추론 → 기본 주행 명령
LiDAR → 라바콘·동적 장애물 판단 → 회피 명령
카메라 → 신호등 검출 및 상태 판단 → 신호등 제어 명령

각 명령은 drive MUX로 전달되며, MUX가 최종 `/xycar_motor` 명령을 발행합니다.

현재 통합 MUX의 명령 우선순위는 다음과 같습니다.

신호등 > 라바콘 > 동적 장애물 > 기본 주행

## 기술적 구현

### PilotNet 기반 학습 주행

전방 카메라 이미지에서 상단 영역을 제거하고 200×66 크기로 변환한 뒤 YUV 입력을 생성합니다. CNN은 조향각과 속도를 회귀하며, 라벨 정규화 정보를 모델 가중치와 함께 저장합니다.

학습 코드에는 밝기 증강이 포함되어 있고, 학습과 추론에서 동일한 전처리 및 정규화 규격을 사용하도록 구성했습니다.

### OpenCV 기반 차선 인식

어안 카메라 보정과 HSV 마스크를 적용해 흰색·노란색 차선을 검출합니다. 차선 오차를 PD 제어에 반영하며, 디버그 영상과 HSV 튜너로 환경별 설정을 조정할 수 있습니다.

이 차선 주행 구성은 E2E 기반 통합 주행과 별도로 실행할 수 있습니다.

### 연속 스캔 기반 동적 장애물 회피

LiDAR ROI 내 전방 장애물을 클러스터링하고, 연속 검출 조건이 충족되면 장애물 반대 방향으로 회피합니다.

회피 중에는 방향을 유지하며, 정해진 횟수만큼 연속 미검출되면 제어권을 기본 주행으로 반환합니다. 미검출 횟수는 새 LiDAR 스캔을 기준으로 계산합니다.

### 신호등 검출과 미션 제어 연결

YOLO ONNX 모델로 신호등 외함 위치를 검출하고, 색상과 4구 슬롯 위치를 이용해 신호 상태를 판별합니다. 연속 프레임 확인을 통해 출발 게이트와 좌회전 동작에 연결합니다.

### MUX 기반 제어권 관리

미션별 노드는 자신의 명령과 활성 상태를 발행합니다. MUX는 우선순위와 명령 유효 시간을 확인해 최종 출력을 선택하며, 주행 복귀 시 가속 제한을 적용합니다.

### ROS 1·ROS 2 통합

ROS 2 인식·판단 노드와 ROS 1 모터 드라이버를 연결하기 위해 Docker 실행 및 ros1_bridge 시작 절차를 통합 launch에 포함했습니다.

## 저장소 구성

| 경로 | 역할 |
| --- | --- |
| `e2e/train.py` | PilotNet 모델 학습 |
| `e2e/`, `e2e_real/` | 모델 가중치 및 정규화 정보 |
| `src/track_drive` | E2E 추론, 데이터 수집, 라바콘 회피, MUX, 통합 launch |
| `src/lane_drive` | OpenCV 차선 인식, PD 제어, HSV 튜너 |
| `src/dynamic_obstacle_avoidance` | 동적 장애물 검출 및 회피 |
| `src/static_obstacle_avoidance` | 정적 장애물 회피 |
| `src/lidar_avoidance` | 차선 주행용 LiDAR 회피·정지 감독 |
| `src/traffic_light_detector` | 신호등 검출, 상태 판별, 튜너 |

| `src/drive_control_msgs`, `src/xycar_msgs` | 제어 인터페이스 |

## 실행 준비

통합 주행에는 저장소 외부의 카메라·LiDAR 드라이버, ROS 1 모터 환경, ros1_bridge, 신호등 ONNX 모델이 필요합니다.

실행 전에 다음 경로를 환경에 맞게 설정해야 합니다.

- E2E 모델 및 정규화 파일
- 신호등 ONNX 모델
- ROS 1 모터 워크스페이스와 Docker 이미지
- ros1_bridge 설치 경로
- 카메라 및 LiDAR 장치 설정

ROS 2 환경에서 빌드 후 통합 launch를 실행합니다.

    colcon build --symlink-install
    source install/setup.bash
    ros2 launch track_drive combined.launch.py
